# 다음에 할 일

아래는 미완료 항목입니다. 완료 작업은 [CHANGELOG](CHANGELOG.md)에 적습니다.

## 실제 플레이 확인

- [ ] 달리기 네 프레임의 크기·발 위치와 착지 전환 확인
- [ ] 점프 높이·충돌 범위가 화면과 잘 맞는지 확인
- [ ] 낮밤 전환 밝기와 점수 가독성 확인

## 안정성 개선 후보

- [ ] 비어 있거나 숫자가 아닌 최고점수 파일의 처리 방침 결정·구현
- [ ] 저장 권한 오류나 쓰기 실패의 안내 방식 결정
- [ ] 필요하다면 실행 이미지·원본·미리보기 하위 폴더 분류

## 선택 가능한 추가 기능 — 아직 구현하지 않음

- [ ] 시작 화면과 조작 안내
- [ ] 점프·충돌·득점 효과음 및 음소거
- [ ] 회피 가능한 범위를 고려한 등장 간격 변화
- [ ] 상한을 둔 점수별 난이도 조절
- [ ] 계절 선택: 이미지 자료는 있지만 현재 게임 적용은 봄 배경
- [ ] 코인·여러 장애물 등 추가 요소
