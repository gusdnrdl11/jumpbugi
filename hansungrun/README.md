# 한성런

한성런은 장애물을 점프로 피하는 Pygame 러너입니다. 기준 폴더는 `hansungrun/`입니다.

## 문서 구조

```text
hansungrun/
├─ README.md                실행 안내와 문서 목차
├─ AGENTS.md                AI 참조 범위 안내
├─ docs/
│  ├─ TODO.md               다음에 할 일
│  ├─ CHANGELOG.md          완료한 작업과 검증 기록
│  ├─ ARCHITECTURE.md       현재 구조와 실행 흐름
│  ├─ STUDY_NOTES.md        사람을 위한 학습 노트
│  └─ archive/              이전 문서·배경 보고서·프롬프트
└─ txt/                     실제 최고점수와 학습 텍스트
```

## 읽는 순서

1. [ARCHITECTURE](docs/ARCHITECTURE.md): 현재 배치와 참조 관계 확인
2. [TODO](docs/TODO.md): 다음 작업 선택
3. [CHANGELOG](docs/CHANGELOG.md): 완료한 작업과 검증 결과

사람을 위한 학습 자료: [쉬운 설명](txt/게임구조_쉬운설명.txt), [STUDY_NOTES](docs/STUDY_NOTES.md). AI의 기본 참조 대상에서는 제외합니다.

## 실행과 검사

확인 환경은 Python 3.13.15, pygame 2.6.1입니다. hansungrun 폴더에서 실행합니다.

```powershell
python main.py
python -B -m unittest discover -s tests -v
```

상위 폴더에서는 `python -m hansungrun.main`으로 실행할 수도 있습니다.

Space: 점프 / Esc: 정지·재개 / 게임오버 후 Enter: 재시작 / Ctrl+F4 또는 창 닫기: 종료

## 계절 배경 순환

배경은 `봄 낮 → 봄 밤 → 여름 낮 → 여름 밤 → 가을 낮 → 가을 밤 → 겨울 낮 → 겨울 밤 → 봄 낮` 순서로 무한 반복합니다.

30초마다 다음 배경으로 전환을 시작하고 기존과 같이 3초 동안 부드럽게 섞습니다. 시작은 봄 낮이며 30초 봄 밤, 60초 여름 낮, 90초 여름 밤, 120초 가을 낮, 150초 가을 밤, 180초 겨울 낮, 210초 겨울 밤, 240초 봄 낮으로 이어집니다. 일시정지·게임오버에서는 전환이 멈추고 재시작하면 봄 낮으로 돌아갑니다.

계절별 낮·밤 PNG 8장은 시작 시 한 번 불러옵니다. 순서는 `config.py`의 `BACKGROUND_FILES`에 있으며 계절이 봄으로 돌아와도 누적 속도와 점수는 유지됩니다.

## 장애물 패턴

상찌·한성캣·기존 꾸꾸까까와 함께 `ggoggoandgguggu_side.png`의 흰색·갈색 캐릭터를 사용합니다. 새 캐릭터는 각각 지상형(높이 96픽셀), 비행형(높이 80픽셀)이 있으며 날갯짓 4프레임과 프레임별 충돌 마스크를 사용합니다.

지상형은 점프로 피하고 비행형은 점프하지 않고 아래로 통과합니다. 비행형의 발끝은 서 있는 한성부기 이미지 상단보다 12픽셀 위에 있어 낮은 장애물과 구별됩니다. 첫 봄 낮·밤(0~60초)에는 새 시트의 날갯짓 지상형·비행형 네 종류를 모두 제외합니다. 첫 여름 낮이 시작되는 60초부터 모두 등장 가능하며, 사계절 한 바퀴를 마친 240초 이후에는 봄에도 무작위로 등장합니다. 재시작하면 첫 봄 제한이 다시 적용됩니다. 기존 정지 이미지 꾸꾸까까는 첫 봄에도 유지합니다.

패턴은 지상 전용 4개와 비행형을 포함한 4개입니다. 예를 들어 `한성캣 → 상찌`, `흰색 비행형 → 상찌 → 한성캣`, `상찌 → 갈색 비행형 → 흰색 지상형` 순서로 등장합니다. 동시에 여러 장애물을 겹치지 않고 이전 장애물이 완전히 사라진 뒤 다음 장애물을 내보냅니다. 속도에 비례해 다음 장애물까지의 접근 거리를 늘려 착지와 다음 판단에 최소 1.2초의 여유를 둡니다. 비행형 바로 아래나 곧바로 뒤에 상찌를 겹쳐 두는 패턴은 없습니다.

8개 패턴을 4단계 속도·3가지 FPS로 검증한 96개 조합에서 회피 경로를 확인했습니다. 자동 플레이는 지상형에 점프하고 비행형에는 지상을 유지해 30·60·120FPS에서 각각 10분 생존했습니다. 사람의 실제 조작감은 추가 확인 대상입니다.

## 점수와 난이도

생존한 온전한 1초마다 1점을 받고 장애물을 통과하면 기존과 같이 10점을 추가합니다. 예를 들어 35초 생존하고 4개를 통과하면 75점입니다. 일시정지·게임오버 동안 시간과 점수가 멈추며 재시작하면 이번 판 점수·생존 시간·속도가 초기화됩니다. 기존 최고점수 파일은 유지합니다.

30초마다 낮·밤 배경 전환이 시작될 때 배경과 장애물 속도를 직전의 1.05배로 올립니다. 30초 1.05배, 1분 1.1025배, 3분 1.3401배, 5분 1.6289배이며 상한은 없습니다. 점프 속도와 중력은 유지합니다. `config.py`의 `SURVIVAL_POINTS_PER_SECOND`, `PASS_BONUS`, `SPEED_INCREASE_RATIO`에서 조절합니다.

실제 키 입력·렌더링을 포함한 최신 자동 플레이는 안전 간격을 적용한 새 패턴으로 30·60·120FPS에서 각각 10분 생존했습니다. 사람의 조작감과 장시간 난이도는 추가 확인 대상입니다. [검증 결과](docs/DIFFICULTY_REPORT.json)는 다음 명령으로 재현할 수 있습니다. 실제 최고점수 대신 임시 파일을 사용합니다.

```powershell
python -B tools/verify_difficulty.py --output docs/DIFFICULTY_REPORT.json
```

## 충돌 판정

실제 출력 크기로 변환한 PNG의 알파값이 127보다 큰 픽셀로 마스크를 만듭니다. 투명 여백과 구멍은 충돌하지 않으며, 달리기 4프레임과 점프 때 표시하는 첫 프레임에 맞춰 판정합니다. 사각형은 빠른 후보 검사에만 사용합니다.

가장자리를 스쳤을 때의 부담을 줄이기 위해 장애물 마스크만 설정 비율만큼 안쪽으로 줄입니다. 현재 설정 6%에서 120픽셀 장애물은 7픽셀, 40픽셀 상찌는 2픽셀입니다. 이미지 자체는 바꾸지 않으며 `config.py`의 `COLLISION_ALPHA_THRESHOLD`, `OBSTACLE_MASK_INSET_RATIO`에서 조절합니다. 마스크는 시작할 때 한 번 생성해 재사용합니다.

검증 내용은 [CHANGELOG](docs/CHANGELOG.md), 구성과 데이터 흐름은 [ARCHITECTURE](docs/ARCHITECTURE.md), 직접 플레이 확인 항목은 [TODO](docs/TODO.md)에 기록합니다.

## 파일 관리 원칙

문서는 docs, 이미지는 image, 점수와 기존 텍스트는 txt, 자동 검사는 tests에 둡니다. 실제 최고점수인 `txt/high_score.txt`는 보존합니다.

AI는 [AGENTS.md](AGENTS.md)의 참조 범위를 따릅니다. 상위 `../study/`, `txt/`의 학습 자료, `docs/STUDY_NOTES.md`, `docs/archive/`는 사용자가 명시적으로 요청할 때만 참조합니다. `txt/high_score.txt`는 실행 데이터로 보존합니다. 현재 실행 안내는 이 README와 ARCHITECTURE를 따릅니다.

완료 작업은 CHANGELOG, 미완료 작업은 TODO, 구조 변경은 ARCHITECTURE, 학습 내용은 STUDY_NOTES에 적습니다. 경로를 바꾸면 관련 문서 링크도 함께 갱신합니다.
