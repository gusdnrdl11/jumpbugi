## 현재 기준과 완료 이력

Pygame 기준본은 `desktop_prototype/`에서 480×360으로, 독립 웹 버전은 `web/`에서 640×360으로 실행됩니다. Pygame의 실제 최고점수는 `txt/high_score.txt`, 웹의 기본 결과는 브라우저 localStorage에 저장합니다. Pages는 기존 정적 모드입니다. 별도 `server/`에는 로컬 FastAPI·PostgreSQL, 사용자 등록·완료 결과 제출/조회·공동 기록·중복 처리·실패 재시도가 구현되어 있습니다. loopback의 `?server=1`에서 선택하며 클라우드·인증·점수 위변조 검증·분석 파이프라인은 향후 범위입니다. 실제 실행 검증 완료 여부는 날짜별 CHANGELOG를 따릅니다.

닉네임 설정은 같은 UUID의 현재 이름만 바꾸며 브라우저 기록·개인 최고값·과거 DB 결과를 유지합니다. 서버 공동 기록판은 현재 이름, 과거 결과 조회는 당시 이름을 사용합니다. 현재 이름 2~12자와 과거 결과 이름 1~40자의 검증 범위는 [BACKEND](BACKEND.md#닉네임과-기록의-이름)에 구분합니다.

이전에 이 문서에 반복하던 완료 체크 목록은 다음 기존 기록으로 연결합니다. 완료 사실과 당시 검사 범위·수치를 보존하되, 당시 결과를 새 실행 결과로 해석하지 않습니다.

## Pygame 기준본의 선택적 체감 확인

아래 직접 조작 항목은 자동 검증과 구분합니다. 자동 테스트 통과를 사람의 플레이 감각 확인으로 간주하지 않습니다. 중복되던 낮밤·계절 가독성과 비행 높이 확인 항목은 각각 하나로 모았습니다.

- [ ] 실제 플레이에서 시작 배경 전환 속도와 달리기 연결의 체감 확인
- [ ] 현재 마스크 설정(큰 장애물 7픽셀·상찌 2픽셀 여유)으로 직접 플레이하며 점프 타이밍의 체감 확인
- [ ] 사이클별 속도·간격·패턴 변화의 직접 조작감 확인
- [ ] 실제 플레이에서 낮밤 밝기·계절 사이 풍경 전환과 점수 글자 가독성 확인
- [ ] 실제 플레이에서 상·중·하 비행 높이 식별, 중간 높이의 거리감, 점프/지상 유지 판단과 장애물 간격의 체감 확인
- [ ] 실제 플레이에서 높은 점프·머리 위 점프는 지상 유지, 낮은 점프는 뛰어넘기로 구별되는지 체감 확인
- [ ] 실제 플레이에서 빠른·느린 진입/탈출 식별과 구덩이 통과 판단 체감 확인
- [ ] 실제 플레이에서 높은·낮은 상찌 혼합 무리의 식별과 점프 판단 체감 확인
- [ ] 실제 플레이에서 거대 한성캣의 표정 변화 속도와 점프 회피 타이밍 체감 확인
- [ ] 실제 플레이에서 달리는 한성캣의 넘어짐·두 점프 식별과 회피 판단 체감 확인

- [x] 2026-11-26 실제 Chrome·Edge의 분리된 프로필에서 자연 게임오버 결과 제출, 서로 다른 사용자 ID, 재로딩 보존과 공동 기록 확인
- [x] 같은 브라우저 보고서의 player_id·run_id를 실제 PostgreSQL 행과 대조하고 각 결과가 정확히 1행이며 제출 내용이 보존됨을 확인 — 상세 증거는 CHANGELOG·WEB_REVIEW
- [x] 닉네임 변경·동일 이름의 서로 다른 ID·재접속 뒤 같은 UUID와 로컬 기록/최고값 보존, 현재 players 이름과 과거 runs 이름의 SQL 대조 — API 14개·Node 45개와 실제 Chrome/Edge 검사
- [x] 이미 저장된 과거 payload를 QA 대기열에 넣은 재시도가 현재 이름·점수·행 수를 바꾸지 않음을 확인
- [x] 2026-11-27 시작 대기·게임오버의 닉네임 입력·저장·취소, 시작 연출·플레이·일시정지 중 제한과 키보드·IME 이벤트 격리 — 실제 Chrome/Edge 각 10개 검사 묶음·모바일 터치 모사·직접 SQL 확인
