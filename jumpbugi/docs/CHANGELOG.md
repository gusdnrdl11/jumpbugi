### 달리기를 유지하는 시작 배경 페이드

- 시작 키를 누르면 화면이 즉시 바뀌던 흐름을 `ready → transition → playing`으로 나눴다. `START_FADE_SECONDS=2.0`초 동안 흰 배경이 사라지며 한성대 봄 낮 배경이 나타나고, 제목·안내도 함께 사라진다. 검정 화면을 거치지 않는다.
- 키 입력으로 상태를 초기화하지 않고 부기의 위치와 달리기 시간을 유지한다. 전환이 끝나면 달리기 시계를 플레이 애니메이션에 이어 주어 자세가 끊기지 않게 한다.
- 전환 중에는 추가 키 입력을 무시하고 점수·계절·장애물을 멈춘다. 부기는 계속 달리며 전환 완료 후 장애물이 움직인다. 게임오버 후 Enter 재시작은 기존처럼 한성대 배경에서 바로 시작한다.
- README·ARCHITECTURE·TODO·GAME_IDEA의 시작 흐름과 전환 시간 설정 설명을 갱신했다.
- 시작 연출 검사 12개를 포함한 전체 75개 자동 검사가 통과했다. 실제 픽셀의 페이드 시작·중간·완료, 부기 원본 알파 보존과 달리기 자세 연속, 30·60·120FPS에서의 2초 전환, 상태 동결·종료·재시작을 확인했다. 화면 캡처로 전환 외관도 확인했으며 Python 파일 17개의 문법 검사도 통과했다. 검사는 임시 점수 파일을 사용했다.

### 사계절 낮·밤 자동 순환

### 생존 점수와 30초 가속

- 생존한 온전한 1초마다 1점씩 추가하고 통과 보너스 10점은 유지했다. 정지·게임오버 중에는 득점하지 않고 재시작 시 시간·점수·속도를 초기화한다. 합산 점수의 최고점수 저장도 검사했다.
- 낮·밤 전환 시작인 30초마다 배경과 장애물 이동을 직전의 1.05배로 가속한다. 점프 물리는 유지하고 가속 시 충돌 검사 간 이동량이 커지지 않도록 세부 계산 간격을 줄였다. 속도 상한은 추가하지 않았다.
- 현재 사용자가 설정한 장애물 마스크 축소율 5%는 유지했다. README·ARCHITECTURE의 이전 2% 설명을 실제 설정에 맞췄다. 기존 충돌 테스트는 축소된 작은 상찌도 몸통과 확실하게 겹치는 x=60으로 배치했다.
- 실제 마스크로 21단계×3종×161개 거리, 총 10,143번의 단일 점프를 탐색했다. 모든 검사 단계에서 장애물별 회피 가능한 거리를 확인했다. 탐색 범위는 x=80~400, 2픽셀 간격이다.
- 고정 시드 20261111, 실제 Space 키 이벤트·렌더링을 포함한 자동 플레이: 30FPS 402.167초/3892점, 60FPS 402.317초/3892점, 120FPS 401.875초/3891점. 각각 350번 점프 후 한성캣 접촉으로 종료했다. 봇은 단계별 단일 점프 성공 거리의 중앙에서 점프하므로 최적 플레이나 사람의 실력을 의미하지 않는다.
- 초반부터 5분 구간의 점진적 난이도로 적용 가능하다고 판단했다. 5분 배율은 1.6289배, 10분은 2.6533배다. 6분 이후 연속 회피 난이도와 사람의 체감은 별도 확인 대상으로 남겼다. [검증 원본](DIFFICULTY_REPORT.json), 재현 도구 `tools/verify_difficulty.py`를 추가했다.
- 전체 자동 검사 28개 통과. 점수 경계·가산·정지·저장·가속 경계·FPS 독립성과 기존 이미지·충돌 회귀를 포함한다. 테스트와 자동 플레이는 실제 최고점수 대신 임시 점수 파일을 사용했다.

### 투명 이미지 기반 충돌 판정

- 기존 축소 사각형 판정을 실제 출력 이미지의 알파 마스크로 변경했다. `Rect`는 빠른 후보 검사와 통과 점수 계산에 유지한다.
- 플레이어 달리기 4프레임과 점프 첫 프레임의 마스크를 실제 출력과 일치시켰다. 사이드 이미지는 크기·정렬 기준으로 유지한다.
- 장애물 윤곽만 높이의 약 2%만큼 안쪽으로 깎았다. 큰 장애물은 2픽셀, 상찌는 1픽셀 여유를 둔다. 알파값 127 이하의 희미한 가장자리와 투명 여백·구멍은 충돌에서 제외한다.
- 시작 시 마스크를 한 번 생성하고 백에 전달해 재사용한다. 백은 화면이나 원본 이미지를 직접 읽지 않는다.
- 실제 4프레임×3종 장애물×3높이×7가로 위치×원본/완화 마스크, 총 504가지 배치를 독립적인 알파 픽셀 집합 비교와 대조해 충돌·게임오버 결과 일치를 확인했다.
- 장애물 가장자리 접촉은 허용하고 안쪽 윤곽 접촉은 게임오버가 되는 이동 검사를 통과했다. 3종 장애물 모두 x=160에서 점프해 30·60·120FPS에서 회피·착지·득점하는 것도 확인했다.
- 이전 상찌 검사는 이미 가까운 x=60에서 점프하던 것을 접근 전 x=120으로 수정했다. 기존 사각형에서 허용되던 상황이라도 실제 그림이 겹치면 새 판정에서 충돌할 수 있다.
- 검증: `python -B -m unittest discover -s tests -v`, 총 23개 통과. 샌드박스의 임시 폴더 접근 제한으로 승인된 권한에서 실행했다. 실제 창의 장시간 조작감은 TODO에 별도 확인 항목으로 남겼다.
